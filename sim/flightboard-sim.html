The flight board, pixel for pixel

Live arrivals and departures from Home Assistant, drawn exactly as the panel will draw them — same Picopixel glyphs, same column positions, same rule for fitting a city name into whatever room the status word leaves. Every row carries the IATA code and, where it fits, the city name. Thirty real flights turned out to be enough to break three things that thirty invented ones never would have.

The window

Home Assistant sends fifteen flights spanning two hours either side of now, with the index of the next one. The panel shows seven of them and puts that next flight on the second line: one behind for context, the rest ahead. The marker down the left edge is it.

What thirty real flights changed

A half word is worse than a code

The old rule shaved a character at a time until the name fitted, which turned Basel's EUROAIRPORT into EUROAIRPOR — a typo, not an abbreviation. It now drops whole trailing words, then any dangling connector, and stops at the code if the first word still will not fit. Basel reads BSL.

The code earns its place

AeroAPI's “city” is the commune: BLAGNAC for Toulouse, EUROAIRPORT for Basel, ORLY for Paris. The code is the part that is never wrong, so it is drawn first and unconditionally, with the name as context on top. Paying for it cost four pixels of column and two status words: ENROUTE and DELAYED were the widest on the board, and shortening just those two bought back four destinations their full name. 27 of 30 live rows now show code and city together.

Picopixel's U was a V

Stock Picopixel draws U as V with one extra row: both end in a single centred pixel. ZURICH read ZVRICH, EDINBURGH read EDINBVRGH — a quarter of the destination column. That is the same one-pixel ambiguity that disqualified TomThumb. The fix gives U a flat bottom, the form Org_01 uses: one bit in the font bitmap, every other glyph byte-identical.

What is actually on the wire

One retained MQTT topic per airport and direction. A few hundred bytes, already digested — the panel holds no API key, makes no HTTP call, and parses no dates.
